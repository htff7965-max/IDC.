# IDC — الهوية الرقمية (النسخة الحقيقية)

الديمو القديم (idc-demo-v8.html) زي ما هو ومتغيّرش. ده مشروع جديد جنبه بنفس الشكل والأقسام، لكن بباك اند حقيقي.

## الملفات (وإيه اللي بيعمله كل واحد)

| الملف | الدور |
|---|---|
| `supabase/schema.sql` | **الباك اند كله**: الجداول، الحماية (RLS)، الباسورد الإضافي للقسم الخاص، الجهات المعتمدة، التخزين، صفحة الكارت العامة |
| `web/js/auth.js` | تسجيل الدخول، إنشاء حساب، نسيت كلمة المرور بالموبايل + SMS |
| `web/js/app.js` | **جمع بيانات المستخدم** (شاشة `onboard`)، وكل شاشات التطبيق |
| `web/js/lock.js` | قفل التطبيق (باسورد / بصمة / Face ID) وتشفير نسخة الأوفلاين |
| `web/js/vault.js` | القسم الخاص: باسورد منفصل + رمز SMS + قفل بعد دقيقتين |
| `web/js/api.js` | الاتصال بـ Supabase (قراءة وكتابة البيانات والملفات) |
| `web/js/i18n.js` | عربي / English (كل النصوص هنا) |
| `web/index.html` + `css/app.css` | الفرونت اند والشكل |
| `web/u.html` | الصفحة العامة اللي بتفتح من كارت NFC أو QR |
| `web/sw.js` + `manifest.webmanifest` | تثبيت التطبيق على الموبايل (PWA) والعمل بدون إنترنت |

## ازاي تبدئي (بالترتيب)

**1) أنشئي مشروع Supabase**
- ادخلي supabase.com، اعملي حساب، New project، اختاري كلمة مرور لقاعدة البيانات واحفظيها.

**2) شغّلي الباك اند**
- من القائمة: SQL Editor، New query، الصقي محتوى `supabase/schema.sql` كله، واضغطي Run. لازم يخلص من غير أخطاء.

**3) إعدادات الدخول (Authentication)**
- Providers: خلّي **Email** شغال، و**اقفلي Confirm email** (عشان التأكيد بيتم برقم الموبايل).
- Providers: فعّلي **Phone**، واختاري مزوّد SMS (Twilio مثلًا) وحطي بياناته. من غير مزوّد SMS مفيش رموز تحقق.
- Multi-Factor: فعّلي **Phone** MFA (Enroll + Verify). ده اللي بيشغّل رمز الـ SMS عند فتح القسم الخاص. الأسماء ممكن تتغير في لوحة Supabase، فدوري على Phone MFA.
- URL Configuration: حطي رابط موقعك في Site URL.

**4) اربطي الفرونت اند**
- افتحي `web/js/config.js` وحطي `SUPABASE_URL` و`SUPABASE_ANON_KEY` (من Project Settings > API) و`SITE_URL`.
- ممنوع تحطي `service_role` key في أي ملف.

**5) شغّليه على جهازك**
- لازم من سيرفر محلي (مش بالضغط المزدوج على الملف). من مجلد المشروع:
  `npx serve web -l 3000` وافتحي `http://localhost:3000`
- أو VS Code + إضافة Live Server.

**6) جرّبي بالترتيب**
1. إنشاء حساب (الاسم + إيميل + موبايل + باسورد) ← رمز SMS ← تأكيد.
2. شاشة بياناتك الأساسية ← شاشة باسورد التطبيق (وتفعيل البصمة لو الجهاز بيدعمها).
3. أضيفي وثيقة عامة بصورة أو PDF، وبعدها افتحي القسم الخاص (باسورد + SMS) وأضيفي وثيقة خاصة وسرية بتاريخ.
4. اقفلي التطبيق وافتحيه: هيطلب الباسورد أو البصمة من غير تسجيل دخول جديد.
5. افصلي الإنترنت: هتشوفي البيانات العامة فقط.

**7) النشر**
- اسحبي مجلد `web` على Netlify (Drag & drop) أو استخدمي Vercel أو GitHub Pages. لازم **https** عشان البصمة وتثبيت التطبيق.
- حدّثي `SITE_URL` في `config.js` والـ Site URL في Supabase بالرابط الجديد.
- على الموبايل: افتحي الرابط ← "إضافة إلى الشاشة الرئيسية".

**8) كارت NFC (NTAG213)**
- من التطبيق: الإعدادات ← رابط الكارت. انسخيه واكتبيه كـ URL record على الكارت بتطبيق NFC Tools.
- الرابط بيفتح `u.html` وبيعرض بس الوثائق اللي علّمتيها "إظهارها في صفحة الكارت".

## إزاي الحماية شغالة (ومستوياتها)
- **كلمة مرور الحساب** (Supabase Auth) للأونلاين.
- **كلمة مرور فتح التطبيق / البصمة** على الجهاز: بتفتح التطبيق وبتفك تشفير نسخة الأوفلاين (AES-GCM، المفتاح مغلّف بكلمة المرور PBKDF2 وبمفتاح الجهاز).
- **القسم الخاص والسري**: الباسورد الإضافي متخزن في السيرفر كـ bcrypt، وبعده رمز SMS، والـ RLS في قاعدة البيانات بترفض أي قراءة للخاص والسري لو الخزنة مش مفتوحة (حتى لو حد عدّل في الفرونت اند). بتتقفل بعد دقيقتين، وبعد 3 محاولات غلط بتتحظر دقيقة، وكل محاولة بتتسجل.
- **الأوفلاين**: بيانات عامة فقط. الخاص والسري مش بيتخزنوا على الجهاز أصلًا.
- **السري بتاريخ**: بعد التاريخ بيتحول لعام تلقائيًا في السيرفر نفسه.

## حدود لازم تعرفيها
- البصمة هنا عن طريق WebAuthn: نظام الموبايل هو اللي بيتحقق منك، لكن المتصفح بيحمي فتح التطبيق مش أكتر. للحماية الأعلى مستقبلًا: لفّي المشروع كتطبيق Capacitor.
- رمز الجلسة (Supabase) محفوظ في المتصفح عشان تفضلي مسجلة دخول، وقفل التطبيق بيمنع أي حد من استخدامه على جهازك.
- لو الجهاز اتفقد: سجّلي خروج من أي جهاز تاني وغيّري كلمة مرور الحساب.
- الرقم القومي والبيانات الحساسة محتاجة مراجعة قانونية قبل الإطلاق للجمهور (خصوصًا في التعامل مع جهات حكومية).
